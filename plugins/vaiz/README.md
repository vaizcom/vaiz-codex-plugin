# Vaiz plugin

Plugin package for ChatGPT and Codex.

- `plugin.json` and `mcp.json` are the portable Agent Plugins manifests.
- `.codex-plugin/plugin.json` and `.mcp.json` provide Codex compatibility metadata.
- `skills/` contains focused guidance for the full Vaiz MCP tool set.
- `assets/vaiz-logo.png` is used in plugin install surfaces.

The MCP server is hosted at `https://api.vaiz.com/mcp`; authentication is handled through OAuth, and no API tokens are stored in this repository.

See the [repository README](../../README.md) for installation and development instructions.
