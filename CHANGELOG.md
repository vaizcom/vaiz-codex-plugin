# Changelog

## 1.0.1

- Skills now tell the agent that Vaiz tools may be deferred and must be loaded through tool search instead of being treated as missing.
- Skills forbid falling back to the browser or Computer Use for Vaiz.

## 1.0.0

- Initial portable plugin for ChatGPT and Codex.
- Added the hosted Vaiz MCP server at `https://api.vaiz.com/mcp` with OAuth.
- Added skills for Space Memory, tasks, projects, milestones, documents, files, workspace activity, GitHub links, and Vaiz help.
